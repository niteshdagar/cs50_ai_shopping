The task in this problem is to build a nearest-neighbor classifier to predict weather a particular customer on a e-commerce website will make a purchase.
Given information about a user — how many pages they’ve visited, whether they’re shopping on a weekend, what web browser they’re using, etc. 
our classifier will predict whether or not the user will make a purchase. the machine learning model used for this task is nearest-neighbor classifier 
and we’ll measure two values: sensitivity (also known as the “true positive rate”) and specificity (also known as the “true negative rate”).
